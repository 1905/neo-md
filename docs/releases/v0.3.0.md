- Automatic updates. neo-md checks GitHub Releases for a new version, downloads it and installs it when you quit the app. No dialog shows. The next start runs the new version. To switch this off, open Settings (⌘,) > General and clear **Install updates automatically**.
- The welcome window is removed. neo-md runs only while a document is open. If you start neo-md without a file, it shows the Open panel. If you cancel the panel or close the last document, neo-md quits.
- Documents that open in the Raw or Split view open faster (about 60 to 100 ms). neo-md makes the Render view only when you show it.
- The VIM button is removed from the toolbar. To use Vim key bindings, open Settings > General and select **Vim** in the **Key bindings** row. The default is **Normal**.

Requires macOS 14 or later (Apple silicon). The app is ad-hoc signed and not notarized. On the first launch, right-click the app and choose Open, or run:
`xattr -dr com.apple.quarantine /Applications/neo-md.app`

Updates install only into neo-md in an Applications folder. Versions 0.2.1 and older have no updater: install 0.3.0 from the DMG one time.
